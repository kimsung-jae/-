# 보글사다리3 삼치기 Hedge V2 · 독립판

- PASS 없음 / 매회 삼치기 추천
- 제외 전용점수로 4개 조합 중 1개 자동 제외
- 통계/패턴/상태 3계열로 묶어 비슷한 엔진의 중복 몰표 억제
- 잘못 제외한 엔진·계열에 더 강한 Hedge 벌점
- 최근 8/15/30, Markov 1/2, 연속상태, 유사상황 검색, Binary 2-Bit, Regime Adaptive
- 강/보통/약 등급과 등급별 순차검증 성공률
- 백그라운드 자동추첨/자동채점/다음 삼치기 자동계산
- 앱 화면 1초 카운트다운, 알림창 백그라운드 카운트다운
- API 반영 지연 시 12초 간격 최대 3회 재확인
- 기본 배팅금액 최소 5,000원
- 기존 V1 SharedPreferences/고정서명키 유지

> 모델점수/등급은 실제 당첨확률이 아닙니다. 균등 무작위 삼치기 기준 성공률은 75%입니다.
