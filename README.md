# 보글사다리3 실전 최강 1픽 V2

삼치기 기능을 제거하고 좌/우, 3줄/4줄, 홀/짝 중 순차 백테스트와 현재 신호가 가장 좋은 1개만 자동 선택하는 Android 앱입니다.

## 주요 기능
- 좌/우 · 줄수 · 홀짝 3개 항목을 각각 별도 엔진으로 분석
- 최근6/10/20/30, EWMA, 전이1/2, 연속/교차, Regime, 직전조합 조건 모델
- 미래 데이터 누설 없는 순차 검증
- 3개 항목의 현재 신호 + 전체/최근 검증성적을 결합해 최강 1픽 선택
- 다음 3분 추첨까지 카운트다운
- 백그라운드 Foreground Service 자동 수집/채점
- 알림창에 다음 추첨시간 / 1픽 / 구간 / 배팅계획 / 실전 승률 표시
- 사용자가 기본 배팅금액과 배당 직접 설정
- 누적 가상수익 기록
- 저신뢰 구간: PASS 또는 기본배팅 선택 가능
- 제한 마틴
  - 기본배팅
  - 1패 후 유효구간 ×2
  - 2패 후 강승구간일 때만 최종 ×4
  - 당첨 시 즉시 기본배팅으로 복귀
  - 최종 ×4 결과 후 승패 관계없이 체인 종료
- JSON 백업/복원

## 중요
모델 신뢰점수는 실제 당첨확률이 아닙니다. 마틴은 기대값을 높이는 기법이 아니며 연속 실패 시 손실폭을 키울 수 있습니다. 이 앱은 무한 마틴을 막기 위해 최대 ×4에서 강제로 종료합니다.
